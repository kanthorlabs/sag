# Release v1.1: MySQL

The `mysql` adapter ships after v1. It implements `sql.Dialect`, reuses the layer gate of README section 7, and passes the conformance suite and the e2e harness as `root`. This file holds no task breakdown.

Required items from PRD section 15.3:

- Minimum server version MySQL 8.4.
- Dependencies `github.com/go-sql-driver/mysql` and `github.com/pingcap/tidb/pkg/parser` at one pinned commit.
- Render with the parser `Restore` function. Send only the rendered text. Parse and validate the rendered text again. Executable comments (`/*! ... */`, `/*T! ... */`) never reach the server.
- `RequestBegin` sets one fixed `sql_mode` and `SET NAMES utf8mb4`. The parser uses the same `sql_mode`.
- `RequestBegin` runs each `SessionGuard` statement again, then `START TRANSACTION READ ONLY`.
- An explicit MySQL function allowlist. The side-effect function list becomes a conformance test list.
- Reflection walk over the TiDB AST with a field allowlist for each allowed node type.
- A table of effects that only C1 blocks: `SET GLOBAL`, `GET_LOCK`, `FLUSH`, `SELECT ... INTO OUTFILE`, `SLEEP`, implicit commit by DDL.
- Reject every relation in the `mysql` schema, with a case-insensitive schema compare. Preflight refuses a DSN with default database `mysql`.
- Reject all optimizer hints.
